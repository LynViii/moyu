## 更新助手

`verify_updates.ps1` 使用隔离目录的真实进程，不替换工作区 EXE。使用版本 0.5.1/0.5.2 的专用测试程序验证：

- 正常安装：原进程退出前目标文件不变，退出后替换、新程序完成带令牌的启动确认、保留静默启动方式。
- 新版启动失败：恢复原 EXE，记录回滚结果，重新打开旧程序。
- 取消：不替换、不关闭原程序。
- 下载哈希错误：拒绝安装，原程序仍可使用。
- 目标被占用：替换重试失败后保留原文件并重新打开原程序。

每种用例均核对目标 EXE 哈希和用户偏好文件哈希。测试清理等待自身进程退出，不依靠强制结束仍在正常退出的实例。正在运行用户实例时会提示先关闭，避免单实例交接误认为测试启动。
