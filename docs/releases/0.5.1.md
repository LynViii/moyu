# 摸鱼 0.5.1

性能复查与本地封存版本，保持现有图标、界面、动画节奏和功能。

- 优化 Win11 默认流畅动画的局部缓冲与 UI 帧消息投递；非键盘消息直接跳过退出匹配。
- 默认场景本机测得约 50.8 Paint FPS，CPU 时间较 0.5.0 两次对照下降约 45%–54%，私有内存均值约 28.0 → 26.5 MiB。仅代表本机短时场景，不是所有模式保证。
- Win10/节能保留原有渲染策略，隐藏/最小化暂停。真实托盘进程 10 秒观测 CPU 时间 0ms，受系统计时精度限制。
- 新增局部/完整帧像素一致性、GDI 生命周期检查与可复测的开发资源测量脚本。
- 源码附接管文档和本地封存脚本，可从 GitHub 或完整 Git bundle 恢复。原工作副本保留，GitHub 不设只读归档。

下载 `moyu.exe` 或便携 ZIP 即可运行；0.5.0 可在应用内检查更新。程序未签名，Windows 场景动画仍为自绘近似。开始菜单真实关闭、物理热插拔和混合 DPI 等限制详见 `docs/VALIDATION_0.5.1.md` 与 `docs/HANDOFF.md`。
