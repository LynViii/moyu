# 摸鱼 0.2.0

本轮加入五项功能：自定义 1–240 分钟、三档动画速度、可取消的 5 秒延迟开始、本次用时统计、命令行快捷开始。

保留三个状态、动态预览、可选扩展屏黑屏、设置保存、单实例、显示器事件处理与 Esc 返回。

统一版本来源，并追溯整理共 21 轮交付历史。历史序号不是历史正式版本或 Git 提交数。

下载 `Moyu-0.2.0-win-x64.exe` 后运行即可。名称可改为 `摸鱼.exe`。需要 Windows x64 与 .NET Framework 4.x。

此文件未签名；作者签名尚未实施。动画为自绘复现。物理热插拔与混合 DPI 待进一步实测。

回归已覆盖：自定义设置恢复、命令行填入、5 秒启动/取消、用时统计、预览、多屏事件重建、最小化恢复、Esc 和定时退出清理。
