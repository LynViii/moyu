# 摸鱼 0.3.0

这一版聚焦场景与显示体验，不加入数据管理功能。

1. Windows 10 / Windows 11 场景直接切换。
2. 蓝底、黑底、自定义浅色和跟随场景配色。
3. 中英文状态文案。
4. 三档文字大小。
5. 指定显示器，断开时回退主屏。
6. 1–60 秒可取消启动倒计时。
7. 可选节能动画。
8. 恢复默认，应用前可取消。
9. 首页快捷键。
10. 内置离线更新日志。

保留窗口预览、三种常用状态、自动返回、多屏黑屏、单实例和 Esc 退出。设置页已进行 200% DPI 渲染检查。

不提供命名方案、设置导入导出、会话历史或 CSV 导出。参考 Fake-Update 的场景选择思路，未复制代码与图片。动画为近似复现，浅色为自定义主题，不宣称与 Windows 原生画面逐像素一致。

源码按 src / assets / scripts / tests / docs 分类，EXE 改为 Release 附件；旧 Git 历史保留。

下载 `摸鱼.exe` 可直接运行，也可选择包含同一 EXE 和简短说明的 `moyu-0.3.0-win-x64.zip`。不需要安装，不需要额外图标或数据文件。程序未做代码签名。

已验证：场景/背景矩阵、动画像素变化、文字大小、偏好记忆、设置页取消和恢复默认、倒计时、预览、Esc、自动返回、显示器事件重建、主屏回退。物理热插拔与混合 DPI 尚未完整实测。
