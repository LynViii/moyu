# 摸鱼 0.4.0

常驻托盘与快捷伪装版本。

- 点击关闭后默认驻留通知区；双击恢复、右键开始/结束/退出。
- 全局 Alt+L 弹出提示并倒计时进入伪装；可选其他快捷键，冲突会提示。
- 首页选择 1–60 秒后开始，提示框支持取消、Esc 和立即开始。
- 移除自动退出；从托盘发起的伪装结束后返回托盘。
- 可选登录 Windows 后静默驻留，在设置中显式开启，默认关闭。
- Win11 使用连续圆弧，Win10 保留经典圆点。
- 伪装时可在指定秒数后收起前台开始菜单，系统快捷键仍保留。
- 新增 --silent、--exit；原有单文件便携、多屏和三种常用状态继续可用。

开始菜单实际闭环测试在当前前台程序抢焦点的环境中未完成；计时、重置和前台目标保护已验证。开机项启停实测后恢复原状态，未执行注销或重启验证。动画为自绘近似。详见 docs/VALIDATION_0.4.0.md。

下载 moyu.exe 可直接运行，ZIP 内文件名为摸鱼.exe，两者相同。启用开机启动后保持路径有效，移动后重新应用开机选项。程序未签名。
