# 摸鱼 0.5.0

应用内更新与可自定义退出按键。

- 首页、托盘可检查正式版本，查看说明后下载并安装，无后台自动更新。
- 校验下载来源、SHA-256、版本、产品名称与架构；原位更新保留路径和设置，新版启动失败恢复旧版。
- 退出方式支持 Esc、连续两次 Esc、方向键序列、Ctrl+Alt+Q 与自定义录制；按住重复不计次数，检测启动快捷键冲突。
- 开始前提示当前退出方式，托盘继续保留结束伪装入口。
- Win11 圆弧加粗，Win10 圆点不变。仍是自绘近似，并非系统动画资源。
- 保留原有图标与简洁布局，新增功能主要收进设置；更新窗口打开时避免误启动伪装。

首次从 0.4.0 升级需手动下载此版本，此后可使用应用内更新。下载 moyu.exe 可直接运行，ZIP 内文件名为摸鱼.exe，两者内容一致。安装目录需要可写；未做代码签名，SHA-256 不等于签名认证。

测试覆盖真实进程的替换、启动失败回滚、取消、校验失败和文件占用恢复，以及实际全屏的方向键退出。开始菜单真实闭环仍受本机前台程序抢焦点影响，未完成实测；未进行物理显示器热插拔、混合 DPI 或重启登录验证。详见 docs/VALIDATION_0.5.0.md。
