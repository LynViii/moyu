# 摸鱼 0.3.1

归档前修复版，聚焦可用性和稳定性，不增加数据管理功能。

- 修复高 DPI、小屏下首页超出可用区域，主按钮固定在底部，内容可滚动。
- 切换 Win10/Win11 保留手动配色。
- 保留暂时断开的显示器偏好，不因修改其他选项被覆盖。
- 设置保存失败显示提示，恢复后自动清除。
- 窄屏与英文大字号自动换行，圆点与文字整体居中。
- 增加使用真实渲染逻辑的场景缩略图。
- 调整动画调度，合并待绘制请求，隐藏和最小化时暂停；增加真实 Paint 帧间隔测量。
- 扩充针对性回归、资源清理与独立 EXE 检查。

下载 `moyu.exe` 即可运行，ZIP 内为同内容的 `摸鱼.exe`；SHA256SUMS.txt 与下载附件名称一致。本机原始路径保持不变。

圆点动画是近似复现，浅色为自定义背景。物理多屏热插拔和混合 DPI 尚未完整实测，不宣称所有机器都能稳定 60 FPS。程序未做代码签名。详细验收见仓库 docs/ARCHIVE_CHECK.md。
