# 0.4.0 验证记录

日期：2026-10-26。构建为 .NET Framework 原生 x64 单文件 EXE，资源嵌入，保留原本机路径。

最终自动回归输出 `ALL TESTS PASSED`，另明确输出一项 `NOT VERIFIED`：真实开始菜单前台闭环。该未验证项不计为实测通过。普通动画 10 秒测量约 51.21 Paint FPS，中位帧间隔 15.92ms、P95 30.86ms；节能约 15.98 FPS。数字只代表本机测量。

## 已验证

- 关闭首页驻留托盘、恢复窗口、显式退出后图标与快捷键资源清理。
- Windows 原生全局快捷键注册及重复注册冲突；WM_HOTKEY 消息触发提示框。
- 提示框倒计时、取消、关闭按钮、立即开始，启动后返回托盘。
- 真实 EXE 使用 --silent 时没有可见主窗口且保持运行，第二次正常启动唤起已有窗口，标题栏关闭驻留，--exit 干净退出。
- 真实当前用户 Run 项带引号的路径和 --silent 写入、删除；测试 finally 恢复原有项，不替用户开启开机启动。
- 首页 1–60 秒记忆；旧 --minutes 不再保存或触发自动退出；自动退出代码与 UI 已移除。
- Win10 / Win11 × 四种配色、中英文与字号、缩略图/预览/全屏共享渲染、动画像素变化。
- 当前环境枚举到两屏，覆盖窗口数量、指定目标屏幕及黑屏行为通过；显示器事件重建保留动画时钟并清理旧窗口。
- 窄屏、大字号、小工作区、设置页恢复默认、写入失败与恢复、动画隐藏/恢复检查。

## 开始菜单：部分验证

开始菜单保护仅在伪装期间轮询。只有前台进程确认属于开始菜单、经过选定等待秒数，且用户未按住 Shift/Ctrl/Alt/Win 时，才重新检查目标并发送一次 Esc。结束伪装后停止轮询。

已通过：计时截止、菜单关闭后重置、重新打开重新计时、非目标前台窗口拒绝。没有拦截 Win 键，也没有安装键盘钩子。

真实桌面闭环 **未验证**。本次前台全屏程序持续抢回焦点，测试无法保持开始菜单在前台，输出 `NOT VERIFIED`。这不作为功能实测通过；需要在正常桌面进入伪装、按 Win 并等待设定秒数再确认。不能将定时状态模拟等同于真实 Shell 关闭结果。

## 测试入口

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run_all.ps1
```

完整套件包含托盘与当前用户开机项测试，需要交互桌面权限。受限沙箱曾返回全局快捷键注册错误 5；在普通用户交互桌面重新测试后注册与冲突检测通过。

`verify_modes.ps1` 检查不自动退出和显示生命周期；`verify_scenes.ps1` 覆盖场景/偏好；`verify_fixes.ps1` 保留布局、文字和帧间隔检查；`verify_executable.ps1` 验证独立进程；`verify_desktop.ps1` 验证系统集成，真实开始菜单未覆盖会明确报告。

## 边界

- 未执行真实注销或重启。开机项写入与 --silent 进程启动分别验证，不据此宣称已做登录后实测。
- 未进行物理显示器热插拔、所有 Windows 版本或混合 DPI 组合测试。
- 连续圆弧参考现代 WinUI ProgressRing 的外观，为本地自绘近似，不是 Windows 原版动画资源。
- 应用没有用户历史、CSV 或设置导入导出；测试截图/报告仅为开发验收输出。
- 开机启动默认关闭；可在更多设置的常驻与快捷键页开启。程序移动后需重新应用开机选项，使路径更新。
