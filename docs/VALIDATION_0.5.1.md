## 封存与恢复验收

运行 `scripts/seal_local.ps1` 生成唯一命名的本地快照，禁止覆盖已有封存。脚本要求工作区干净、HEAD 与版本标签一致，收集发布程序、源码 ZIP、完整 Git bundle、旧 work 资料和开发证据。

封存过程执行 `git bundle verify`，在 `.build` 的全新目录离线克隆，核对提交 SHA，重新构建并运行 `verify_executable.ps1`。成功后移除 INCOMPLETE 标记，写入 `SEALED.txt`、manifest 和 SHA-256，并运行封存自身的校验脚本。检查失败时保留未完成目录，不将其当作成功快照。

本地封存路径见 `HANDOFF.md`；原 outputs/work 保留，当前 EXE 路径不变，远程仓库维持可写状态。之后应在新目录/分支接管，不修改已校验的快照。恢复验证不等于编译结果逐字节可重现。
