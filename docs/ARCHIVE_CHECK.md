# 0.3.1 归档前检查

检查日期：2026-09-28。范围：本线程上一轮列出的全部问题、修复后的回归与可执行程序交付。

最终结果：`tests/run_all.ps1` 输出 `ALL TESTS PASSED`；独立 EXE 复制启动、单实例交接及实际窗口截图检查通过。其中一次完整回归的普通动画 10 秒检查为 46.78 FPS、中位数 16.46ms、P95 31.22ms、最大 32.90ms。本轮可验证范围内未发现未修复的阻断问题；未覆盖边界见文末。

## 修复对应关系

| 检查项 | 处理与证据 |
| --- | --- |
| 小屏与高 DPI 首页越界 | 根据工作区限制窗口，内容可滚动，开始按钮独立固定；测试 1280×720、1024×768、800×600、640×480 工作区 |
| 设置页小屏按钮裁切 | 列宽限制为可用宽度，底部三按钮比例布局；640×480 截图与按钮可达性断言 |
| 手动配色丢失 | 首页切换场景保留显式配色，与设置页一致；light → Win10 回归 |
| 离线显示器偏好丢失 | 添加未连接选项并保留设备名；默认重置仍可恢复自动选屏 |
| 保存失败无反馈 | 保存方法返回成功状态，首页显示非打断提示；模拟目标不可写、检查临时文件清理和恢复后提示消失 |
| 长文案与大字号裁切 | 先测量和换行，再整体定位；空间不足时缩小文字；英语大字号三状态四尺寸边界与截图检查 |
| 动画缺少真实帧测量 | 使用实际 Application.Run 消息循环和 Paint 回调测量；不以 timer.Interval 推算 FPS |
| 场景选择不直观 | 同一渲染器生成静态缩略图，跟随当前状态、字号、语言、配色 |

## 动画测量

对照使用 `tests/measure_animation.ps1 -Seconds 30`，窗口客户区 1040×600，分别运行保留的 0.3.0 EXE 与修复版。两次顺序运行，不是严格受控性能实验。

| 指标 | 0.3.0 | 0.3.1 |
| --- | ---: | ---: |
| 实测时长（秒） | 30.010 | 30.023 |
| 有效帧间隔样本 | 1199 | 1397 |
| Paint 频率（FPS） | 39.95 | 46.53 |
| 帧间隔中位数（ms） | 30.15 | 16.47 |
| P95 帧间隔（ms） | 34.24 | 31.53 |
| 最大帧间隔（ms） | 50.81 | 47.76 |
| 超过 50ms 的样本 | 1 | 0 |
| 超过 100ms 的样本 | 0 | 0 |

后续短回归中也出现过约 54ms 的单次长帧，因此不作零掉帧或恒定 60 FPS 保证。Paint 频率不是屏幕最终呈现频率，也没有测量 GPU/display 延迟。

动画回调只请求 UI 线程绘制，最多保留一个待处理请求；隐藏和最小化时暂停，恢复时继续。没有修改持久系统计时或电源设置。节能模式刻意降低刷新频率。

计时与 UI 线程模型核对了微软文档：[Windows Forms Timer](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.timer)、[Threading Timer](https://learn.microsoft.com/en-us/dotnet/api/system.threading.timer)、[Control.BeginInvoke](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.control.begininvoke)。

## 回归范围

- `tests/verify_modes.ps1`：偏好恢复、命令行、倒计时、预览、Esc/自动返回、显示器事件重建、事件与定时器清理。
- `tests/verify_scenes.ps1`：两场景×四背景、颜色、字号、像素变化、异常配置、指定屏幕与回退、设置取消/默认值、快捷键。
- `tests/verify_executable.ps1`：复制单个 EXE 到新目录后启动、标题与版本、单实例交接、关闭；可选真实窗口捕获。
- `tests/verify_fixes.ps1`：本轮针对性检查、小屏截图、文字边界、保存失败恢复、普通/节能动画测量与隐藏恢复。
- `tests/run_all.ps1`：按顺序执行所有项目，任意失败立即停止，另跑 DPI-unaware 逻辑 96 DPI 检查。

生成的测试截图和帧报告位于 `.build/acceptance/` 与 `.build/test-results/`，不作为应用数据、不进入用户会话历史。

## 尚未验证的边界

- 本次环境只枚举到一个物理显示器。多屏逻辑和显示器变化事件有测试，但真实插拔、不同缩放率组合仍需双屏实机验证。
- 96 DPI 兼容检查不等同于另一台物理 100% 缩放机器；小工作区通过布局约束模拟，未改动用户显示器分辨率。
- 动画为自绘近似，不是 Windows 原版资源；不同系统版本的原生页面也不保证一致。
- 程序未签名，未做跨 Windows 版本与杀毒软件兼容性认证。
- 极窄窗口允许水平滚动以保持控制项可达，不宣称任意尺寸下都能一次显示所有选项。

归档建议：完成自动检查、源码同步、Release 附件校验后，可作为当前个人用途版本归档；不能将这些检查解释为任何环境下绝对无缺陷。归档操作由用户决定，本轮不会自动将 GitHub 仓库设为只读。
